# Python To-Do List

A command-line To-Do List application developed using Python.

## Features

- Add tasks
- View tasks
- Complete tasks
- Edit tasks
- Delete tasks
- Store tasks using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Exception Handling

## Project Description

This project is a command-line based To-Do List application.
It allows users to create, view, update, complete and delete tasks.
The task data is stored in a JSON file so that the data can be
saved and accessed again when the program is run.

## Skills Demonstrated

- Python programming fundamentals
- Functions and modular programming
- Lists and dictionaries
- File handling
- JSON data storage
- Exception handling
- User input and validation
- Basic problem solving

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run `main.py`.
